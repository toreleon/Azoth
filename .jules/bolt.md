## 2026-08-24 - Optimize Array Allocations in Hot Paths
**Learning:** Chained array methods (`.map()`, `.slice()`, `.reduce()`, `.filter()`) in data-heavy pipelines like ticker discovery create massive garbage collection overhead. Pre-allocating arrays and using single-pass indexed `for` loops yields significant CPU and memory improvements.
**Action:** When refactoring hot paths, replace array method chains with direct `for` loops. For filtered maps, pre-allocate `new Array(length)` and track a separate counter to build the array in-place, then truncate it with `length = count` before sorting.
