## 2024-05-18 - [Time-Series O(n) Filter Bottleneck in Backtesting]
**Learning:** During backtesting, arrays of chronologically sorted market data (e.g., Ohlcv bars) were being repeatedly filtered using `bars.filter(b => b.time <= asOf)` to resolve prices at a specific point in time. Filtering an array of thousands of bars for every symbol on every simulation interval is an O(n) operation per lookup, generating a severe CPU and memory allocation bottleneck on the hot path.
**Action:** Replace `Array.prototype.filter` with a reusable binary search utility (`findLastBarIndex` in `dnsePublic.ts`) for all time-series historical price lookups, dropping the complexity to O(log n) and removing the massive allocation overhead. Always prefer O(log n) array searches over O(n) array filtering on chronologically sorted time-series market data for performance critical paths.
