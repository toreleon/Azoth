## 2024-06-19 - O(N) filtering in Backtest runner hot loop
**Learning:** The `backtestRunner.ts` logic loops through historical timeframe points and was using `Array.prototype.filter` sequentially to find the last price closing index up to the current as-of-time (i.e. `bars.filter(b => b.time <= asOf)`). Since financial time-series data is chronologically sorted, filtering the entire historical dataset on every backtest iteration and for every ticker scales at O(N) when it can be done in O(log N).
**Action:** Use the `findLastBarIndex` utility (now exported from `src/data/sources/dnsePublic.ts`) for fast binary search price lookups, instead of traversing arrays linearly with `.filter()`. Avoid doing array allocations and traversals inside tight loops in the backtest runner.
